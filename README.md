# CryptoProject
  objective: create an application with a GUI that allows encrypting, decrypting, and hacking two ciphers - a Time Based Cipher (AKA TBC) and the infamous Yonch cipher. with a secure log in authentication using hash libraries saved in a .json file 

# features
- an authentication page: using a username and password. crypted !unhackable! password
- encryption and decryption of the Yonch cipher with a detailed example tab built in
- encryption, decryption, and hacking of the TBC with a custom key/using the current time
- coherent pages with functional and useful buttons

# HOW TO RUN THE SITE
- install zip from https://github.com/doramelech/CryptoProject
- open in pycharm
- run in the terminal: pip install -r requirements.txt
- run run_app.py
